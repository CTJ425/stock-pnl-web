A test that pinned the old behaviour was rewritten; new tests assert 保本價 equals the first price where the displayed net reaches 0 and that one cent the other way is negative, across four rates, long and short.
- **Residue, named so nobody re-opens it**: `estimateUnrealized` rounds to whole dollars, so one cent below 保本價 the card can still read 0 — worth at most **NT$0.50**. Display granularity, not a fee-model disagreement.
