# BUG-085 — Watchlist group of 8150 (南茂) flips between 半導體業 and 其他

## Root cause (verified 2026-09-23)

- The watchlist groups each item by `prices['TPE:<ticker>'].industry` (`WatchSection.tsx:160`), with fallback to `getStockCategory` (dictionary, then name heuristic).
- Edge `stock-price` returns `industry` only on a fresh MIS fetch (`misParse.ts:200`). The DB cache-hit path (`index.ts:319`) and the Yahoo path (`index.ts:232`) return `industry: null`, because `price_cache` has no `industry` column.
- The client polls every 60 s. A poll served from MIS gives `半導體業`; a poll served from `price_cache` gives `null`.
- 8150 is not in `COMMON_STOCK_INDUSTRIES`, and the name `南茂` matches no heuristic, so `null` resolves to no category → `其他`. Result: the card moves between groups.

## Contract

1. `price_cache` stores `industry TEXT` (nullable). Additive DDL only.
2. Edge `handlePrices` writes `industry` on the TW/US upsert and reads it back on a cache hit, so a cache hit returns the same `industry` as the MIS fetch that filled the row.
3. `getStockCategory('8150', '南茂')` returns `'半導體'`.
4. Must NOT change: the FX path (`key FX:*`, its select/upsert), TTL logic, any other `Quote` field, RLS policies, client code other than the dictionary entry.
