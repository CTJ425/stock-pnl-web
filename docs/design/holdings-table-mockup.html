🎯 1. 移除分組列市值與損益（效益分析）

  • 徹底解除視覺干擾：原本在分組列第 8、9 欄掛著兩組數字，既非全欄加總、又缺乏對應表頭，閱讀時視線容易被這兩個浮空數字打斷。
  • 資訊不重複（DRY 原則）：表格正上方的 MarketPanel 已經有清楚的「多單市值」、「空單市值」曝險尺與「總未實現損益」，分組列重複計算只會徒增視覺負擔。
  • 通欄標籤（colspan="10"）更易識別：改為區塊分隔標題後，多空分段一目了然，並能容納更清楚的 Badge（例如「▲ 多單 2 檔」）。

📏 2. 字級大小微調方案（黃金尺寸對照）

  • 現行痛點：數值 12.5px、次級資訊（淨收/未含費）僅 10.5px，在 2K / 4K 或一般筆電螢幕下非常吃力。但若盲目擴大到 16px，10 欄表格會嚴重橫向溢出。
  • 建議微調（+1px ~ +1.5px 階梯微升）：
    • 表格主數值 / 股名：12.5px → 14px 黃金舒適尺寸
    • 次級資訊（未含費/淨收/券商）：10.5px → 11.5px 不再瞇眼
    • 表頭欄位名稱：12px → 13px
    • 垂直內距（Padding）：9px → 11px（提升行間呼吸感，保持橫向緊湊）
