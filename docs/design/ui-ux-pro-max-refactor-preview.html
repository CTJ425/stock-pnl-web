🎯 UI/UX Pro Max 全面重構技術分析與建議架構 (Executive Summary)

1. 視覺語意與圓角階層 (Geometric Harmony)

現行版本全面採用 IBM Carbon 的 0px 嚴格銳角，在企業工具雖嚴謹但對一般投資人過於冰冷且生硬。建議升級為 Neo-Fintech 幾何階層：卡片 10px、按鈕/輸入框 6px、標籤 4px，保留高密度專業感的同時提升現代美學。

2. 凍結欄位與行動端圖卡切換 (Data Table UX)

台股長表超過 10 個欄位，在平板與小螢幕滑動時容易遺忘標的。重構加入 Sticky Frozen Columns (代號與名稱固定於左側)，並支援與自選股一致的 「表格 ↔ 圖卡」模式無縫切換，徹底解決行動端破版或橫向滑動負擔。

3. 數字排版與台股紅綠色彩校正 (Color & Monospace)

數字統一強制啟用 font-variant-numeric: tabular-nums 與 Fira Code 等寬對齊，避免跳動。針對深色模式升級高辨識度熒光珊瑚紅 (#ff4d5e) 與祖母綠 (#10b981)，解決 0.9.38 曾發生的 CSS 權重覆蓋問題。

4. 5,300+ 行單一 CSS 模組化解耦 (Architecture)

現行 sources/src/index.css 達 5,355 行且殘留已非 glass 的 .glass 命名。建議將 CSS 解耦為 tokens.css、components/table.css、components/card.css，或評估引進 Tailwind CSS v4 徹底根治樣式專一性衝突。
