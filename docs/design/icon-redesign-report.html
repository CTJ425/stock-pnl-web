⚠️ 痛點 1：尺寸碎片化（12 種零散尺寸）
目前全專案在各組件中任意手動傳入 size={11}、size={12}、size={13}、size={14}、size={15}、size={16}、size={17}、size={18}、size={28}、size={30}、size={32}、size={36}。

後果：按鈕內的圖示與字體比例失衡，小尺寸（11-13px）在標準 24px 網格下邊界半像素渲染導致線條發虛。
🔤 痛點 2：Unicode Emoji 與向量圖示混用
在 ProbeWarRoom 中使用 🟢 探測中、✅ 已退休；交易紀錄通知使用 🎉 成功新增、🗑️ 已刪除；警語使用 ⚠️；股價漲跌使用 ▲、▼。

後果：Emoji 在 Windows、macOS、Linux、iOS 渲染出的形狀與顏色天差地遠，無法配合網站的深淺主題換色，顯得像業餘拼湊。
🧩 痛點 3：缺乏統一的 Icon 設計系統層
所有 28 個前端組件都是直接 import { ... } from 'lucide-react'。若未來想要全站升級自訂金融圖示庫、加上 Micro-fill 雙色調、或是統一行為（如預設 aria-hidden="true"），需要逐一修改 120+ 處代碼。

解法：封裝 <AppIcon name="..." size="..." /> 統一入口。
📈 痛點 4：缺乏金融專屬的視覺語彙
目前多數圖示使用通用線條。金融看盤與損益系統的核心在於「漲跌清晰、權重分明、資料密集」。

建議：針對大盤指數、持股分析、試算器、籌碼流向引入微漸層（Red/Green Fin-Accent）與發光指示點。

📊 現行尺寸分佈統計

尺寸 (Pixel) 出現頻率 主要代表組件與情境 規範化收斂建議
11px ~ 13px 約 32 處 表頭排序箭頭 (12)、選單 Caret (12)、折疊 Minus/Plus (13)、狀態標籤 (12) 收斂為標準 Token: xs (12px)
14px ~ 15px 約 48 處 選單按鈕 (14)、搜尋前綴 (15)、CSV 上傳/匯出按鈕 (15)、刪除圖示 (14) 收斂為標準 Token: sm (14px) 與 md (16px)
16px ~ 18px 約 22 處 主要導航 Tab (15/18)、AI Bot 標題 (18)、關閉按鈕 (18) 收斂為標準 Token: lg (20px)
28px ~ 36px 約 16 處 空狀態 (36)、大圖表分析 (32)、載入等待 (28) 收斂為標準 Token: xl (32px)

📐 圖示系統重構設計指南 (Icon System Blueprint)

1. 尺寸階層定義 (Size Tokens)

Token 名稱 像素值 (px) 筆觸粗細 (strokeWidth) 適用使用情境
--icon-xs 12px 2.0px 表格欄位升降冪排序 (SortableTh)、微型狀態指示點、行內標籤
--icon-sm 14px 1.75px 次級功能按鈕、下拉選單項目、輔助標籤、搜尋框清除 X
--icon-md 16px 1.75px 主要操作按鈕 (CTA)、搜尋前綴圖示、表單輸入框前綴
--icon-lg 20px 1.5px 頂部主要分頁導航、手機底部導航欄、模態框標題
--icon-xl 24px 1.5px 功能卡片強調圖示、重點操作入口、浮動操作按鈕
--icon-2xl 32px 1.25px 空狀態 (Empty State) 插圖、大成就/完成反饋徽章

2. 統一封裝元件提案：<AppIcon />

// sources/src/components/Common/AppIcon.tsx import { FC, SVGProps } from 'react'; import * as Icons from 'lucide-react'; export type IconSizeToken = 'xs' | 'sm' | 'md' | 'lg' | 'xl' | '2xl'; const SIZE_MAP: Record<IconSizeToken, { size: number; strokeWidth: number }> = { xs: { size: 12, strokeWidth: 2.0 }, sm: { size: 14, strokeWidth: 1.75 }, md: { size: 16, strokeWidth: 1.75 }, lg: { size: 20, strokeWidth: 1.5 }, xl: { size: 24, strokeWidth: 1.5 }, '2xl':{ size: 32, strokeWidth: 1.25 }, }; export interface AppIconProps extends Omit<SVGProps<SVGSVGElement>, 'size'> { name: keyof typeof Icons; size?: IconSizeToken | number; className?: string; } export const AppIcon: FC<AppIconProps> = ({ name, size = 'md', className, ...props }) => { const IconComp = Icons[name] as FC<any>; if (!IconComp) return null; const config = typeof size === 'string' ? SIZE_MAP[size] : { size, strokeWidth: 1.75 }; return ( <IconComp size={config.size} strokeWidth={config.strokeWidth} aria-hidden="true" focusable="false" className={[`app-icon app-icon-${size}`, className].filter(Boolean).join(' ')} {...props} /> ); };
