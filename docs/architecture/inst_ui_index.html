三大法人買賣超 - 設計提案

為解決原表格在時間序列對比、手機端橫向捲動以及資訊層級不佳的問題，以下提供 6 種不同資訊架構的獨立展示。

1. 矩陣視圖 (Unit-as-row matrix)

概念：將單位作為列、時間作為欄，並加入熱力圖標示強度。解決跨日對比困難的問題，讓外資是否連買連賣一目了然。
權衡：不易在同一個畫面塞入買進/賣出毛額（legs）。

2. 發散長條圖 (Diverging bar chart)

概念：以每日為一列，中心為 0 軸，左右發散長條圖（紅買綠賣）。解決原始表格缺乏量級感受的問題。
權衡：確切的小數字較難精確閱讀，需要互動式提示框。

3. 卡片流 (Card-per-day flow)

概念：將每一天壓縮成一張精簡卡片，水平排列。點擊可展開該日的詳細部位。解決預設展開/收合帶來的資訊雜訊。
權衡：追蹤單一單位橫跨七天的連續趨勢相對困難。

4. 主從分割檢視 (Split master–detail)

概念：左側列出所有單位與總結，右側顯示選取單位的完整 7 日明細。解決時間序列難以閱讀，同時又保留了毛額數據。
權衡：需要點擊才能查看不同單位的細節。

5. 專業終端視圖 (Terminal dense view)

概念：無展開收合，一次攤平所有單位的買賣超數據，採用固定寬度與顏色編碼，適合高頻交易員。
權衡：手機版體驗極差，非常依賴寬螢幕與使用者的掃描閱讀能力。

6. 行動版折疊過濾 (Mobile-first accordion)

概念：從 390px 寬度出發，使用頂部標籤過濾單位，下方以單行列表呈現每日數據。解決手機端必須水平捲動的痛點。
權衡：在桌機上無法一次看到多個單位並列比較。
