## 1. Background from the research (2026-10-06)

- **Fugle MarketData** is a REST API at `https://api.fugle.tw/marketdata/v1.0/stock/...`, authenticated with
  the `X-API-KEY` header. Deno can call it with plain `fetch`, so no SDK is needed.
- Fubon's 新一代 API serves the same data (時報資訊 + Fugle). It was rejected because it needs the native
  SDK, which does not run on Deno Edge, plus a 富邦 account, a `.pfx` cert or API key on a server, and a
  fixed IP for its allowlist. Supabase Edge egress IPs are not fixed.
- **Plans** (pricing page read 2026-10-06):

  | Plan | Price | Intraday | Snapshot | Historical | 盤後籌碼 |
  |---|---|---|---|---|---|
  | 基本用戶 | free | 60/min | **none** (403, measured) | 60/min | none |
  | 開發者 | NT$1,499/mo | 600/min | 600/min | 60/min | 60/min |
  | 進階用戶 | NT$2,999/mo | 2,000/min | 2,000/min | 60/min | 60/min |

  - The key in use is on the free plan. Responses carry `x-ratelimit-limit` / `-remaining` / `retry-after`.
  - Historical is 60/min on every plan.
- **Terms ("聲明" on the intro page):** users must follow the TWSE / TPEx / TAIFEX 交易資訊使用管理辦法, and
  「轉接交易資訊……或將之傳送予第三人」 is prohibited. This site shows quotes to several accounts. The user
  accepted this risk on 2026-10-06 (「以上內容都允許」); it stays a PROD decision.
- **Overseas IP:** no geo restriction is documented, but none was tested either. The first DEV call in §8
  settles it.

## 3. Facts measured (they drive the code)

- `intraday/quote` `total.tradeVolume` is in 張 (docs say shares). Times are epoch microseconds.
- Minute candles report 張; `IntradayPoint.v` is shares, so ×1000. Only `TSE` / `OTC` are accepted.
- `historical/candles` rejects a span ≥ 1 year for every timeframe (400); no data → 404.
- `adjusted=false` is raw (0050 split shows 188.65 → 47.57); `adjusted=true` also removes dividends.
  Yahoo is split-adjusted only, so `splitAdjust` scales rows before a day whose reference / previous close
  is outside 0.8–1.25.
- Fugle has no industry name; `intraday/ticker` has a code but costs a call, so a ticker with no cached
  industry goes to MIS.
- 5d prevClose: Fugle gives the close of the day before the window (2026-09-29: 2475); Yahoo's
  `chartPreviousClose` said 2480 (the first day's close). Fugle's is the definition the chart claims.

## 4. Fallback rules

Fugle is skipped, and today's path runs, when: no `FUGLE_API_KEY`; the endpoint family is parked after a 429
(until `retry-after`) or 401/403 (10 min); any HTTP / network failure; a closed day (`prices`, BUG-110);
an unparseable or empty answer. `_shared/fugle.ts` never throws.
