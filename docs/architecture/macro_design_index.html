總體經濟與大盤籌碼 UI 重構視覺提案庫

針對「第一眼直覺化視覺 (At-a-Glance Status)」與「層級化圖表下鑽 (Deep-dive Visual Charts)」打造的 6 種不同美學風格雛型展示。

Style 1

高階戰情室 (Executive Dark)

深色戰情室風格，運用微光霓虹色彩與高對比狀態卡片，提供強烈視覺震撼度。

  • 宏觀體溫計 Hero 區塊
  • 上升/下降動量視覺圖示
  • 多維度堆疊長條圖 (Chart.js)
開啟設計展示 (Demo 1)
Style 2

極簡雜誌 (Minimal Editorial)

白底極簡金融雜誌風格，以流暢版型、精緻字型與強烈數字對比呈現清爽質感。

  • 核心觀點 Executive Summary 區
  • 高對比數據指標卡片
  • 簡潔平滑折線趨勢圖
開啟設計展示 (Demo 2)
Style 3

新潮熱力與圖示 (Visual Heatmap)

以顏色熱度 (Hot/Warm/Cool) 與鮮明 Emoji / 經典 Icon 直覺傳遞大盤冷熱狀況。

  • 熱力色彩條狀狀態標籤
  • Emoji 圖像識別 (🚀, 🔥, ❄️)
  • 多指標平行比較網格
開啟設計展示 (Demo 3)
Style 4

Bento 盒與計量儀表 (Bento Grid)

採用現代 Bento Box 模組化佈局，搭配 SVG 半圓形計量儀表盤 (Gauges) 展示利率與通膨目標。

  • Bento Grid 網格分配
  • SVG 半圓計量儀表盤 (Gauge Meter)
  • 緊湊型圖表嵌合技術
開啟設計展示 (Demo 4)
Style 5

專業金融終端 (Financial Terminal)

彭博/TradingView 經典黑底專業終端樣式，高資訊密度、頂部即時 Run-down 跑馬燈與專業圖表。

  • 頂部跑馬燈 (Live Ticker Bar)
  • 高密度等寬字型數據表格
  • 專業 TradingView 風格圖表
開啟設計展示 (Demo 5)
Style 6

新擬物立體風 (Neumorphic & Tactile)

柔和的浮雕與凹陷陰影質感，搭配 LED 狀態指示燈與實體按鈕回饋感，呈現細緻科技美學。

  • 立體陰影面板 (Tactile Inset/Outset)
  • 發光 LED 狀態識別燈
  • 擬真實體切換按鈕
開啟設計展示 (Demo 6)

6 種風格特性與適用場景評估矩陣

風格名稱 視覺焦點 (First Glance) 圖表互動體驗 資訊密度 推薦使用場景
Style 1: 高階戰情室 霓虹體溫計 + Glow 動量卡片 交互式疊加長條圖 / 分頁切換 中高 喜好暗色炫酷 UI，重視視覺衝擊力
Style 2: 極簡雜誌 Executive Summary 摘要 + 大數字 極簡高對比折線圖 中等 偏好閱讀型體驗，追求俐落閱讀質感
Style 3: 新潮熱力圖示 Emoji + 熱力色彩狀態列 (Hot/Cool) 雙色對照長條圖 中高 希望 1 秒內透過色彩與圖示辨識多空
Style 4: Bento 盒與儀表盤 SVG 儀表盤 (Gauge) + Bento 盒 鑲嵌型漸層區域圖 高 現代 UI 潮流，喜歡質感儀表指針視覺
Style 5: 專業金融終端 Top Ticker 跑馬燈 + 高密度矩陣 專業 K 線 / 多軸趨勢圖 極高 操盤手/硬派投資者，追求一屏最大資訊量
Style 6: 新擬物立體風 LED 燈號 + 實體浮雕觸感卡片 陰影凹陷質感圖表框 中等 喜好獨特工藝細節與精緻沉浸感
