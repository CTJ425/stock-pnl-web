Combo Option 1

上下雙區視圖 (Split Table & Chart)

上半部為大型動態折波圖，下半部為完整的歷史數字表格，表格每列內嵌近 7 日 Sparkline 微型折波圖。

  • 上半部 320px 高解析度趨勢折波圖
  • 下半部歷史日期數據表格與差額標籤
  • 表格單元格內嵌 SVG Sparkline 縮圖

Combo Option 2

左右對照視圖 (Side-by-Side View)

左側 60% 空間放置動態折波圖，右側 40% 空間放置精準數字數據表，方便視線水平快速對照。

  • 左側可切換指標的 TradingView 樣式折波圖
  • 右側數據表可切換「台股籌碼」或「美股總經」
  • 實時漲跌紅綠膠囊與連續買賣天數

Combo Option 3

表格主導 + 嵌入式迷你折波圖 (Inline Sparklines)

以詳細數字表格為核心，每一筆指標項目（加權指數、外資、投信、CPI、Fed 利率）直接嵌入 12 期微型折波圖。

  • 清晰的高密度數字與前後期比較列
  • 表格列中直接繪製 12 期迷你折波圖
  • 視覺直覺，可一次閱讀多個指標走勢

Combo Option 4

頁籤連動與同步 Hover 視圖 (Synchronized View)

頂部提供視圖切換（圖表+表格並排 / 僅圖表 / 僅表格），且當滑鼠滑過圖表點位時，下方表格對應日期自動高亮。

  • 頂部 Mode Toggles (Both / Chart Only / Table Only)
  • 雙向 Hover 游標同步聚焦
  • 極高互動性與精準查驗體驗

Combo Option 5

  • 包含 52 週最高/最低範圍與 %CHG 列
  • 專業數據密度與等寬字型排版
